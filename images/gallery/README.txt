Gallery photos.

Make one folder per event and put the photos inside. The folder name becomes the album title.
Start the folder name with a date to sort albums, e.g.  2026-06 ASCO Annual Meeting
A photo file name becomes its caption (camera names such as IMG_1234 are ignored).
